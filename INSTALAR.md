# Como instalar o CybhorPDV

Voce **nao precisa baixar o codigo-fonte**. Basta o instalador.

## Passo a passo

1. Baixe o arquivo **`CybhorPDV-Setup-1.0.0.exe`** em:  
   [github.com/cybhortech/sistemaPDV/releases](https://github.com/cybhortech/sistemaPDV/releases)

2. Execute o instalador e siga as telas.

3. Abra o **CybhorPDV** pelo Menu Iniciar do Windows.

4. No **primeiro acesso**, crie a conta de **administrador**.

5. Pronto — pode usar o PDV normalmente.

## Requisitos

- Windows 10 ou superior
- Conexao com a internet (para sincronizar com o banco de dados)

## Problemas comuns

| Problema | Solucao |
|----------|---------|
| "Falha ao conectar ao banco de dados" | Verifique a internet e reinstale com o instalador mais recente |
| Antivirus bloqueou | Permita o CybhorPDV nas excecoes do antivirus |
| Nao abre apos instalar | Reinstale executando o `.exe` como administrador |
